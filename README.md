TreeOfBirds Script is a component of the Tree GameObject where it is attached in the inspector. It stores the four sparrows in an array where it is controlled when the hidden sparrows pop out as the player gets close. The Update() code constantly checks for every Sparrow in the list whether it is within the interaction distance to pop out. The Vector3 code checks if that interaction distance is more than the distance between the individual bird and the player. Thus, the animation of the bird popping out plays :D
